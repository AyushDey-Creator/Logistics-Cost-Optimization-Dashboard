# 💰 Logistics & Freight Cost Optimization Dashboard

## 📌 Project Overview
An interactive **Power BI** financial analytics dashboard powered by **SQL** data transformations to monitor freight expenditure, evaluate carrier cost efficiency, and track budget variances across global trade corridors.

## 🔑 Key Features & Insights
* **Freight Spend Analysis:** Evaluated total transport costs across ocean, air, and road transit modes.
* **Carrier Cost Efficiency:** Compared cost-per-ton-mile and carrier invoice accuracy to highlight cost-saving opportunities.
* **Variance Tracking:** Monitored actual freight invoice totals against initial estimated costs to detect margin leakage.

## 🛠️ Tech Stack
* **SQL:** Data extraction, joins, variance queries, and spending aggregations.
* **Power BI:** Dynamic financial modeling, DAX cost measures, and budget performance visualization.
